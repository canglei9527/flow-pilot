# v0.4.18 发布介绍：修复单独安装断链、重复确认与仓库校验

发布日期：2026-10-13 · 版本线：0.4.17 -> 0.4.18

v0.4.18 修复维护与初始化 Skill 在独立安装、需求沟通和仓库验证中的问题。只安装其中一个 Skill 时，需求流程参考文件也能完整随包分发；继续同一任务时沿用用户已有选择，减少重复确认和附加工作。

## 本次修复

- **单独安装时参考文件完整。** 旧需求流程引用兄弟目录 `shared/`，只复制一个 Skill 会断链。两个 Skill 现在各自携带本地参考副本；维护时从共享源同步，并检查副本一致性。
- **同一任务沿用需求模式。** 用户已经选择“跳过问卷”或“直接执行”后，继续工作沿用该选择，不重复显示三选一；尚未选择时仍提供可选需求沟通。
- **具体操作授权可以复用。** 已明确授权的推送、发布等操作不重复询问。“直接执行”只控制沟通方式，不授权清理草稿、删除未跟踪文件、操作其他项目或扩大远端操作范围。
- **普通修复和单文件工具减少附加工作。** 普通 Bug 修复不再要求先补建治理目录；MICRO 默认保持单文件，不额外创建维护文档目录。用户明确请求的多个事项仍按阶段验证并持续完成。
- **补回维护与续作的发现信号。** 描述恢复“刷新后又出现”“继续未完成工作”“收尾”“验证归档”等中英文提示；249 字符检查明确为历史兼容预算，不能据此推断所有客户端的可见窗口或触发率。
- **校验器正确区分分发内容与本地文件。** 递归检查参考文档内的 Markdown 链接、真实路径和符号链接边界；忽略的本地会话不阻塞校验，强制加入 Git 的禁止内容仍失败。缺少 `LICENSE` 时汇总错误，避免异常中断；无 Git 的源码归档仍执行目录边界检查。

## 发布验证

- **47 项 Node 测试通过**，其中新增 12 项隔离回归，覆盖单 Skill 复制、递归断链、符号链接越界、副本同步、版本漂移和缺失文件诊断。
- 仓库完整性验证、需求参考副本同步检查和 `git diff --check` 均通过。
- 根据 `evals/prompts.md` 对触发语义、直接执行、文件保护、普通修复和 MICRO 规则进行静态人工评估。
- 本次未运行真实客户端触发测试或网络安装流程；静态与隔离测试结果不代表真实客户端触发率已经验证。本机已安装的 Skill 副本需单独更新。
